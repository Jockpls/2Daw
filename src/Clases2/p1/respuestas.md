# Pruebas

## ¿Por qué no se puede instanciar envío?
- No se puede instanciar envío porque es una clase abstracta, sirve de base para las subsclases que se generen de ella.

## ¿Por qué no se puede acceder a destino desde una hija?
- Porque es un atributo privado

## ¿Por qué no se puede reescribir resumen ni heredar de envío urgente?

- No se pueden reescribir ni heredar porque son un método y una clase final, lo que indica que a partir de ellas no se puede heredar ni modificar el contenido.
